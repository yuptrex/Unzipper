Where do files go?

No folder selection is needed. Each file inside kb.zip downloads automatically using your browser's default download location.

In Chrome/Edge, files are saved into a kb subfolder inside your Downloads folder. If your browser is set to "Ask where to save each file," you may see repeated save prompts — turn that off in browser settings for a fully automatic run.
