Where do files go?

No folder selection is needed. Each file inside kb.zip downloads automatically using your browser's default download location.

In Chrome/Edge, files are saved into a kb subfolder inside your Downloads folder. If your browser is set to "Ask where to save each file," you may see repeated save prompts — turn that off in browser settings for a fully automatic run.

Large archives (multi-GB uncompressed, many files) are supported — files are processed and downloaded one at a time, so overall archive size isn't a problem. The one limit is per-file: a single extremely large file (roughly 2GB+) may exceed what your browser tab can hold in memory at once, since browsers can't stream a decompressing file straight to disk.
